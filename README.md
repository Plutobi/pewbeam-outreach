## 🇬🇧 UK Focus & Features

1. **Preloaded UK Church Pipeline (30 Verified Churches)**:
   - Covers London (HTB, Hillsong London, All Souls Langham Place, Jesus House), Manchester (!Audacious, City Church), Birmingham (Gas Street Church, Renewal), Leeds (Life Church, St George's), Bristol (Woodlands, Severn Vineyard), Glasgow (Destiny, Tron), Edinburgh (Ps & Gs), Cardiff, Oxford, Cambridge, and more.
   - Real ratings, verified websites, and media/tech team contact emails.

2. **1-Click Outreach Station**:
   - **`Copy Email`**: Copies a tailored cold email highlighting Sunday booth panic (unscripted Bible verse quotes, manual slide search) and introducing Pewbeam's real-time AI audio verse projection. Automatically marks the church as **Contacted** with a neon green highlight.
   - **`Copy DM`**: Short DM template for LinkedIn/Instagram.
   - **`Mark Sent`**: Visual tracking and filtering so you never contact the same church twice.

3. **Free UK Scraper (Zero-Cost)**:
   - Discover new churches in any UK city without burning Apify credits or requiring API tokens.

4. **1-Click Mail Merge Export**:
   - Export your filtered UK leads to CSV ready for cold email platforms (**Instantly.ai**, **Smartlead.ai**, **Lemlist**).

## 📦 Push to GitHub

This repository is already initialized and committed on the `main` branch. To publish it to your GitHub:

1. Create a new repository on GitHub (e.g. `pewbeam-outreach`).
2. Run these two commands in PowerShell:
   ```powershell
   git remote add origin https://github.com/YOUR_USERNAME/pewbeam-outreach.git
   git push -u origin main
   ```
*(Your `.env` and secrets are automatically protected by `.gitignore`)*.
