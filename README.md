# ⚡ Pewbeam Automated Church Outreach Hub

An automated lead generation, scraping, and personalized outreach engine built for **[Pewbeam](https://pewbeam.com/)** using Python, Streamlit, and Free Web Discovery.

---

## 🎨 Pewbeam Brand Aesthetic
The dashboard is styled using Pewbeam's signature visual identity:
* **Background:** Obsidian Black & Deep Carbon (`#080707`, `#121010`)
* **Primary Brand Accent:** Radiant Pewbeam Orange (`#ff5700` / `#d44900`)
* **Live Status / Highlights:** Electric Neon Green (`#00ec66`) & Amber Warm Gold (`#ffd2b5`)
* **Borders & Elevation:** Sleek dark glassmorphism with subtle 1px border glow

---

## 🚀 Key Features

1. **🆓 100% Free Built-in Scraper Engine (Zero-Cost / No Apify needed):**
   * Discovers churches and crawls their websites for staff/AV/media emails without any paid API keys or subscriptions.
   * Includes an **Instant Church URL Email Extractor**: paste any church website to inspect and extract contacts in seconds.
   * Also supports **Apify Cloud Scraper** as an optional toggle if you have Apify credits.

2. **📦 270+ Preloaded Verified Churches Starter Pack:**
   * Includes real churches with active media/production teams across:
     * **United Kingdom:** London, Manchester, Birmingham, Leeds, Glasgow, Edinburgh, Bristol, Belfast
     * **Germany & DACH:** Berlin, Munich, Frankfurt, Cologne, Hamburg, Stuttgart, Zurich, Vienna
     * **France & Belgium:** Paris, Lyon, Bordeaux, Marseille, Brussels
     * **Spain:** Madrid, Barcelona, Valencia, Seville, Zaragoza
     * **Netherlands:** Amsterdam, Rotterdam, Utrecht, Veenendaal, Barneveld
     * **Italy:** Rome, Milan, Naples
     * **United States:** Dallas/Fort Worth, Atlanta, Houston, Austin, Nashville, Charlotte, Orlando, Miami, Los Angeles, Chicago

3. **🌍 Native Multilingual Cold Outreach Generator:**
   * Generates culturally accurate cold emails, LinkedIn DMs, and follow-up bumps in:
     * 🇬🇧 **English** (UK / USA / Global)
     * 🇩🇪 **German** (*Deutsch* - Beamerteam, Technikteam)
     * 🇫🇷 **French** (*Français* - Équipe régie, Équipe audiovisuelle)
     * 🇪🇸 **Spanish** (*Español* - Equipo multimedia)
     * 🇮🇹 **Italian** (*Italiano* - Team regia video)
     * 🇳🇱 **Dutch** (*Nederlands* - Beamerteam, Mediateam)
     * 🇵🇹 **Portuguese** (*Português* - Equipe de mídia)
   * 1-Click Export of full mail-merge CSV ready for **Instantly.ai**, **Smartlead.ai**, or **Lemlist**.

## 🖥️ How to Run Locally

Double-click [`run_dashboard.bat`](file:///C:/Users/HP/.gemini/antigravity/scratch/pewbeam-outreach/run_dashboard.bat), or run:
```powershell
cd "C:\Users\HP\.gemini\antigravity\scratch\pewbeam-outreach"
python -m streamlit run dashboard.py
```
Open `http://localhost:8501` in your browser.
